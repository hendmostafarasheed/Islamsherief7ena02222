GITHUB PAGES — CLICKABLE HENNA INVITATION

Upload these 5 files directly to the root of your GitHub repository:
- index.html
- invitation-cover.png
- invitation-details.png
- background-music.mp3
- README.txt

All assets are referenced from the repository root (no assets folder).
Click zones have been adjusted to match the visible circles and the art stretches to the viewport so the zones stay aligned.

Important configuration inside index.html:
- RSVP_WHATSAPP: enter the host's WhatsApp number with country code, digits only (e.g. 2010XXXXXXXX).
- PHOTOS_URL: enter the shareable photos album URL.
- MAPS_QUERY: currently searches Google Maps for "Hilton Hotel Ballroom (A)"; use the exact venue name/address for precise results.

After uploading, wait for GitHub Pages to deploy and refresh the site. Try opening the link in an incognito tab if the old version is cached.
